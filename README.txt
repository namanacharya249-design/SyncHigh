SYNCHIGH MEDIA — OFFICIAL WEBSITE
==================================

HOW TO DEPLOY (3 steps, no editing needed):

1. Create a new GitHub repository named exactly: synchighmedia
   Upload ALL files and folders from this zip into it (keep the
   folder structure: assets/ and images/ must stay as folders).

2. Go to vercel.com -> Add New -> Project -> import the
   "synchighmedia" repository. Do NOT change any settings.
   Framework preset: "Other". Just click Deploy.

3. Done. Your website will be live at:
   https://synchighmedia.vercel.app

SEO SETUP (one-time, after deployment):

1. Go to search.google.com/search-console
2. Add a property: https://synchighmedia.vercel.app
3. Verify ownership (use the HTML tag method if asked —
   or just ask Jarvis to walk you through it).
4. Go to "Sitemaps" in Search Console and submit: sitemap.xml
5. Use "URL Inspection" -> "Request Indexing" for the homepage.

That's it. Google usually indexes a brand-new unique name
within a few days.
